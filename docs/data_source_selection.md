# 데이터 소스 선정

## 선정 결과

주 데이터 소스로 **보건복지부 보도자료 RSS 2.0**을 사용한다.

- 기관: 보건복지부
- 데이터 종류: 보도자료
- 방식: RSS 2.0(XML)
- RSS 주소: <https://www.mohw.go.kr/rss/board.es?mid=a10503000000&bid=0027&info>
- 공식 안내: <https://www.mohw.go.kr/menu.es?mid=a10807000000>
- 인증키: 필요 없음

## 선정 이유

- 보건복지부가 공식적으로 제공하는 공개 RSS다.
- 별도의 API 키 발급 없이 개발과 테스트를 시작할 수 있다.
- 복지, 청년, 고용, 보건의료, AI 등 프로젝트의 분류 주제와 관련된 자료가 포함된다.
- RSS에 본문이 포함되어 있어 별도 웹 페이지 수집 없이도 AI 요약을 시험할 수 있다.
- RSS 구조가 단순하여 첫 데이터 수집기를 구현하기에 적합하다.

## 실제 확인한 데이터 필드

2026-08-27에 RSS 접속과 응답을 확인했다.

| 프로젝트 필드 | RSS 필드 | 처리 방법 |
|---|---|---|
| 제목 | `item/title` | 그대로 저장 |
| 작성일 | `item/pubDate` | 표준 날짜 형식으로 변환 |
| 본문 | `item/description` | HTML 엔티티와 불필요한 공백 정리 후 저장 |
| 기관명 | 고정값 | `보건복지부`로 저장 |
| 원문 URL | `item/link` | 그대로 저장 |
| 작성자 | `item/author` | 선택 필드로 저장 |
| 카테고리 | 피드에 없음 | 이후 AI 분야 분류 단계에서 생성 |
| 수집 시각 | 피드에 없음 | 프로그램 실행 시각을 기록 |

필수 후보 필드 6개 중 제목, 작성일, 본문, 기관명, URL의 **5개를 확보**할 수 있으므로 과제 조건인 최소 4개를 충족한다.

## 이용 정책

- 공식 RSS를 우선 사용하고 일반 웹 크롤링은 하지 않는다.
- RSS에 포함된 텍스트만 수집 대상으로 사용한다.
- 모든 데이터와 리포트에 기관명과 원문 URL을 보존한다.
- 개별 저작물의 공공누리 유형과 이용조건을 준수한다.
- 공공누리 자료를 활용할 때 구체적인 출처를 표시한다.
- 사진, 이미지, 일러스트, 동영상은 수집하지 않는다.
- 요청 실패 시 짧은 재시도만 허용하며 최대 재시도 횟수를 제한한다.

## 호출 정책

- 사용자가 `fetch` 명령을 실행할 때만 RSS를 요청한다.
- 한 번의 `fetch` 실행에서는 RSS를 1회 요청하는 것을 기본값으로 한다.
- HTTP timeout을 설정한다.
- 네트워크 오류가 발생하면 최대 1회만 재시도한다.
- 반복문으로 같은 RSS를 연속 호출하지 않는다.
- 원문 상세 페이지는 기본 수집 대상에서 제외한다.

## 크롤링 정책

현재는 기관이 공식 제공하는 RSS만 사용하므로 HTML 크롤링과 robots.txt 확인이 필요하지 않다. 향후 상세 페이지 수집 기능을 추가할 경우 구현 전에 robots.txt와 사이트 이용 정책을 별도로 확인한다.

## 예비 데이터 소스

주 데이터 소스 장애에 대비한 예비 후보는 과학기술정보통신부 보도자료 RSS다.

- 공식 안내: <https://www.msit.go.kr/contents/cont.do?mId=173&mPid=147&sCode=user>
- RSS 주소: <https://www.msit.go.kr/user/rss/rss.do?bbsSeqNo=94>
- 현재 주 데이터 소스로 사용하지 않는 이유: 확인 시 RSS 요청이 HTTP 400으로 응답하여 안정적인 초기 구현에 적합하지 않았다.
