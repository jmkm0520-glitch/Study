# 프로젝트 정의

## 타겟 사용자

공공기관이나 기업에서 정책, 보도자료, 산업 동향을 정기적으로 확인하고 내부에 공유하는 실무 담당자다.

주요 업무는 다음과 같다.

- 여러 기관 사이트에서 새로운 자료 확인
- 업무와 관련된 자료 선별
- 핵심 내용과 업무 영향을 요약
- 중요한 일정이나 확인 사항 정리
- 수집 결과를 업무 브리핑으로 작성·공유

## 해결하려는 문제

공공정보가 여러 기관과 서로 다른 형식으로 흩어져 있어 담당자가 사이트를 반복해서 방문해야 한다. 비슷하거나 중복된 자료도 많아 필요한 정보를 찾고 요약하는 데 시간이 많이 들며, 수작업 과정에서 중요한 변화나 일정이 누락될 수 있다.

## 해결 방향

Public Brief는 공개 RSS 또는 API의 자료를 자동으로 수집하고 다음 과정을 하나의 흐름으로 처리한다.

1. 원본 데이터 수집 및 저장
2. 데이터 정제와 중복 제거
3. AI를 이용한 핵심 내용과 업무 영향 요약
4. 업무 분야와 중요도 분류
5. 반복 키워드와 주요 이슈 분석
6. Markdown 및 표 형식의 업무 브리핑 생성

## 기대 효과

- 반복적인 정보 확인과 정리 시간 절감
- 중요한 정책 변경과 일정의 빠른 확인
- 자료별 판단 기준과 브리핑 형식의 일관성 확보
- 원문 링크를 통한 결과 검증 가능
